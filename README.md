# Dezgo.lv - Profesionāla Tarakānu Iznīcināšana Latvijā

Modern, SEO-optimized website for a Latvian disinfection business specializing in cockroach extermination services.

## 🌟 Features

- **Modern Responsive Design** - Works perfectly on all devices (desktop, tablet, mobile)
- **SEO Optimized** - Meta tags, structured data, sitemap, and robots.txt for excellent search engine rankings
- **Latvian Language** - Full content in Latvian targeting the local market
- **Fast Loading** - Optimized CSS and JavaScript for quick page loads
- **Interactive UI** - Smooth animations, FAQ accordion, mobile navigation
- **Contact Form** - Easy-to-use contact form with validation
- **Professional Layout** - Clean, modern design that builds trust

## 🚀 Quick Start

### Local Development

1. Clone this repository
2. Open `index.html` in your web browser
3. That's it! No build process required.

### Deployment Options

#### Option 1: GitHub Pages (Free)

1. Go to your repository settings
2. Navigate to "Pages" section
3. Select your main branch as source
4. Your site will be live at `https://yourusername.github.io/Dezgo.lv`

#### Option 2: Netlify (Free)

1. Sign up at [Netlify](https://www.netlify.com/)
2. Drag and drop the project folder
3. Your site will be live instantly with custom domain support

#### Option 3: Vercel (Free)

1. Sign up at [Vercel](https://vercel.com/)
2. Import your GitHub repository
3. Deploy with one click

#### Option 4: Traditional Web Hosting

1. Upload all files to your web hosting via FTP
2. Ensure `index.html` is in the root directory
3. Update the domain in meta tags and sitemap.xml

## 🔧 Customization

### Update Contact Information

Edit `index.html` and replace placeholders:

```html
<!-- Find and replace these: -->
+371XXXXXXXX         → Your actual phone number
info@dezgo.lv        → Your actual email
Rīga, Latvija        → Your actual address
```

### Update Domain Name

After deploying, update these files with your actual domain:

1. **index.html** - Update all `https://dezgo.lv/` URLs in meta tags and schema
2. **sitemap.xml** - Update all `<loc>` URLs
3. **robots.txt** - Update sitemap URL

### Add Images

To add images for better visual appeal:

1. Create an `images/` folder
2. Add your images (logo, services, before/after photos)
3. Update `index.html` to reference your images
4. Recommended images:
   - Logo (logo.png)
   - Service photos
   - Team photos
   - Before/after treatment photos

### Customize Colors

Edit `styles.css` CSS variables:

```css
:root {
    --primary-color: #d32f2f;      /* Main brand color */
    --primary-dark: #b71c1c;       /* Darker shade */
    --secondary-color: #1976d2;    /* Secondary color */
    --accent-color: #ffa000;       /* Accent color */
}
```
